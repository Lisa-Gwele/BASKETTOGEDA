# BasketTogether

A student prototype of a women-focused cooperative grocery savings circle.

BasketTogether is a student prototype using fictional members and simulated transactions. No real savings, loans or payments are processed.

## Files

- index.html: English/Sesotho landing page.
- app.html: interactive English/Sesotho prototype.
- assets/images/: the two supplied AI-generated images used by the landing page.

## Preview

Open index.html in a browser. Select Try the Working Demo to open app.html.

## Upload to GitHub

Upload the CONTENTS of this folder to the repository root. Preserve assets/images and its filenames. Do not upload only the ZIP file or nest the site inside an extra folder.

No build, framework, backend, API keys or dependencies are required. Uploading the source does not require enabling GitHub Pages. An existing Pages deployment may update automatically when changes are committed to its publishing branch.
